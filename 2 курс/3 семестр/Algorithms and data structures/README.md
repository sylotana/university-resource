# Лабораторные по алгоритмам и стурктурам данных для допуска к ЭКЗАМЕНУ
Лабораторные работы, выбор варианта по списку. Оформляется одним отчетом, регистрировать не надо, принести в электронном виде на сессии.

Темы курсовых работ преподаватель скинет вечером

Титульные листы подписывает пачкой, их нужно только зарегистрировать

В электронном виде курсовая работа скидывается преподавателю на почту, примерно ноябрь-декабрь

Критерии оценивания экзамена: в билете 3 задания, 2 теоретических и задача.
По времени отводится 40 минут на теорию, 20 минут на задачу.
2 выполненных задания это тройка.

Задачи:
- [ ] Прочитать методические указания
- [ ] Написать контрольную работу (без помощи ИИ)
- [ ] Отнести на регистрацию
